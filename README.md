# Hospital Management System (MySQL)

A beginner-friendly SQL project that models a hospital database and demonstrates how to manage and analyze hospital information.

## Database Tables
- Patients
- Doctors
- Departments
- Doctor_Department
- Appointments
- Medical_Records
- Billing

## SQL Concepts Practiced
- Database and table creation, primary and foreign keys
- CRUD operations
- Filtering, sorting, grouping, and aggregate functions
- INNER, LEFT, and RIGHT JOINs
- Subqueries
- Date and string functions
- CASE expressions and window functions

## How to Run
1. Open `SQLhospital_management.sql` in MySQL Workbench or another MySQL 8.0-compatible client.
2. Connect to your MySQL server.
3. Execute the script.
4. Explore the sample data and run the included queries.

**Note:** The script drops and recreates the project tables when rerun. Use it only in a practice environment; existing data in those tables will be deleted.

## Purpose
I built this project to practice relational database design and strengthen my SQL skills using a practical hospital-management scenario.
